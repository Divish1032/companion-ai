# Spike Outputs

Use this directory for validation work that informs architecture decisions.

Expected Sprint -1 output:

- `sarvam_streaming_validation.md`: empirical STT/TTS streaming results, latency observations, limitations, and recommendation.

Spike files should include:

- Date.
- Environment.
- Provider/API version if known.
- Test inputs.
- Results.
- Decision impact.
- Follow-up tasks.
